UGC KOREA에서 어떤 일을 할 수 있나요?

크리에이터, 캠페인, 정산처럼 데이터가 정확해야 하는 서비스의 백엔드를 맡을 수 있습니다. 대학병원 급여 시스템에서 다진 "한 원도 틀리면 안 되는" 정산 로직 경험을 크리에이터 보상·정산에 그대로 가져올 수 있습니다.

가장 자신 있는 기술은 무엇인가요?

Java · Spring Boot 기반 API 설계와 Oracle/MySQL 데이터 모델링입니다. 여기에 Docker · Jenkins CI/CD와 AWS 배포까지 혼자 끝낼 수 있습니다.

AI 기능도 다룰 수 있나요?

네. 동글이 프로젝트에서 TensorFlow·Keras로 33만 장을 학습시켜 정확도 96.19%의 모델을 만들고, FastAPI로 분리된 추론 서버를 운영했습니다.

스타트업 환경과 잘 맞나요?

직접 창업해 사업을 운영해 봤고, 프리랜서로 서버 7개를 단독 구축했으며, 6명 팀의 팀장을 맡았습니다. 정해진 역할보다 필요한 일을 찾아서 하는 쪽이 익숙합니다.
